# Reactor Yield Surrogate — Team NextGen

**Fugacity 2026 ML Hackathon · Chemical Engineering Association, IIT Kharagpur**

Round 1 result: **RMSE 10.1953 · MAE 2.6521 · R² 0.9200 — 6th of 374 valid submissions.**

---

## The problem

Predict the overall yield of intermediate product **B** in a non-isothermal continuous-flow
reactor running series kinetics **A → B → C**, from five operating conditions:

| feature | meaning |
|---|---|
| `flow_rate_L_min` | volumetric feed rate |
| `concentration_mol_L` | inlet concentration of A |
| `inlet_temperature_K` | feed temperature |
| `length_m` | reactor length |
| `jacket_temperature_K` | heating jacket temperature |

B is an intermediate, so yield rises, peaks, then collapses. 150 training rows, 50 blind test
rows. The data is noise-free — generated by a deterministic simulator — so residual error is
model mis-specification, not a noise floor.

## The approach

We did **not** fit a black-box regressor. We reverse-engineered the simulator: a mechanistic
reactor model with seven unknown physical constants, fitted to the 150 training rows.

```
da/dt = −k₁·a
db/dt =  k₁·a − k₂·b
dT/dt =  h·(T_jacket − T) + C₀·(q₁·k₁·a + q₂·k₂·b)
k_i   =  k_i(430K)·exp[ −Ea_i/R · (1/T − 1/430) ]        t = z/F,  τ = L/F
```

- **Discretisation** — 35 tanks in series (Pe ≈ 68) for axial dispersion, each solved
  implicitly by damped fixed-point iteration
- **Thermal dispersion decoupled** from mass dispersion (Lewis ≠ 1), λ = 0.10
- **Fitting** — Levenberg–Marquardt least squares, multistart; global optimum confirmed by
  differential evolution
- **Model selection** — 5-fold cross-validation over 8 candidate structures
- **Ensembling** — bagging over 32 bootstrap resamples

Seven parameters against 150 observations ≈ 21:1.

Roughly 3.5× more accurate than the best machine-learning baseline we could construct.

### Recovered physical constants

```
Ea₁ =  45.1 kJ/mol      A → B   (desired)
Ea₂ = 251.9 kJ/mol      B → C   (side)
h   =  3.41             jacket heat transfer
q₁  = −13.33            A → B is endothermic
q₂  = +11.76            B → C is exothermic
```

**Ea₂/Ea₁ ≈ 5.6.** The side reaction is far more temperature-sensitive, so raising
temperature destroys B faster than it forms it. Setting k₂ = k₁ gives a **selectivity
crossover at 449.1 K** — and the raw data collapses to zero yield across exactly that band
(mean yield 23.7 % → 0.2 % between the 430–460 K and 460–490 K bins). Two independent routes,
one threshold.

## Structure search — what we rejected, and why

| structure | in-sample | CV | verdict |
|---|---|---|---|
| series A→B→C, 1st order | 8.27 | 9.75 | baseline |
| + free reaction orders | **3.33** | **41.2** | rejected — best training score, negative CV R² |
| + reaction heat | 3.65 | 7.36 | **kept** |
| + axial dispersion | 3.39 | 6.84 | **kept** |
| + parallel A→C branch | 8.28 | 10.16 | rejected — optimiser drives k₃ → 0 |
| flow-dependent h (Dittus–Boelter) | 3.64 | 7.78 | rejected — m ≈ −0.03 |

Selecting on training error would have chosen the worst model in the study.

## Failure analysis

RMSE 10.20 against MAE 2.65 implies ~2 catastrophic rows among ~48 near-exact ones. Both sit
within 2 K of the 449.1 K crossover. At that point the optimal residence time collapses 100×
(3.16 min at 380 K → 0.03 min at 450 K) — a physically ill-conditioned regime. Our bootstrap
flagged the worst row as the least reliable prediction in the test set *before* submission.

Because the parameters are physical, deployment faults are diagnosable: a drifting `h` means
fouling, a drifting `Ea` means catalyst chemistry, a structured residual with stable parameters
means the model itself is wrong.

## Requirements

Python 3.9+, `numpy`, `pandas`, `scipy`, `scikit-learn`. No GPU, no deep learning frameworks.
A full prediction is a single ODE integration — sub-millisecond, against minutes for the
CFD/BVP route it replaces.
